# 1.南山经

南方的第一列山系叫做䧿 què 山，

第一列山系䧿山，从招摇山到箕尾山，一共有十座山，一千九百五十里。

这些山的山神的形貌都是鸟的身子龙的头。祭祀它们的礼仪，把祭祀用的羽毛、璋、玉埋在地下，祭祀的米用稻米，一边都是稻米，用白菅草制作席位。

南方的第二列山系之第一座山叫做柜山，

南方第二列山系，从柜山到漆吴之山，一共十七座山，七千二百里。这些山的山神的形貌都是龙的身子鸟的头。祭祀：祭祀用的羽毛和玉璧，埋入地下，祭祀的米用稻米。

南方第三列山系之第一座山，叫做天虞山，

南方第三列山系，从天虞山到南禺山，一共十四座山，六千五百三十里。这些山的山神的都是龙的身子人的脸。他们的祭祀都用一只白狗，祭祀的米用稻米。

右边是《南山经》，大大小小一共四十座山，一万六千三百八十里。
