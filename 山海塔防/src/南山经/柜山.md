# 柜山

南方的第二列山系之第一座山叫做柜山，

    西边临近流黄山，北边可以看到诸毗山，东边可以看到长右山。英水从这座山发源，然后向西南流入赤水。

    水中有很多白玉，还有很多粟粒大小的红色沙粒。

    水中有一种野兽，形状像小猪，长着公鸡脚，发出的声音如同狗叫，名字叫狸力，在哪个郡县出现，那里就会有很多水土工程

    山中有一种鸟，形状像猫头鹰却长着人的手，发出的声音如同鹎鸟，名字叫鴸 zhū，它发出的叫声便是它的名字，在哪个郡县出现，那里就会有很多流放的人

东南四百五十里，叫做长右山，

    没有花草树木，山中有很多水。山中有一种野兽，形状像禺猴却长着四只耳朵，它的名字叫长右，发出的声音如同呻吟，在哪个郡县出现，那里就会发生大水灾。

再往东三百四十里，叫做尧光山，

    山南阳面有很多玉石，山北阴面有很多金属。山中有一种野兽，形状像人却长着猪的鬣毛，住在山洞里还会冬眠，它的名字叫猾里，发出的声音如同砍木头，在哪个郡县出现，那里就会有很多徭役。

再往东三百五十里，叫做羽山，

    山下有很多水，山上经常下雨，没有花草树木，有很多蝮虫。

再往东三百七十里，叫做瞿父山，

    没有花草树木，有很多金属和玉石。

再往东四百里，叫做句馀山，

    没有花草树木，有很多金属和玉石。

再往东五百里，叫做浮玉山，

    北边可以看到具区湖，东边可以看到诸毗湖。

    山中有一种野兽，形状像老虎却长着牛尾巴，发出的声音如同狗叫，名字叫彘，是能吃人的。

    苕水从这座山的北面流出，向北流入具区湖，湖中有很多鮆 jì 鱼

再往东五百里，叫做成山，

    形状四四方方上下分为三层，山上有很多金属和玉石，山下有很多青雘 wò。

    䦠 shǐ 水从这座山发源，然后向南流入库勺水，水中有很多黄金。

再往东五百里，叫做会稽山，

    形状四四方方，山上有很多金属和玉石，山下有很多砆 fū石。

    勺水从这座山发源，然后向南流入湨 jú 水。

再往东五百里，叫做夷山，

    没有花草树木，有很多沙石。湨水从这座山发源，然后向南流入列涂水。

再往东五百里，叫做仆勾山，

    山上有很多金属和玉石，山下有很多花草树木，没有鸟兽，没有水。

再往东五百里，叫做咸阴山，

    没有花草树木，也没有水。

再往东四百里，叫做洵山，

    山南阳面有很多金属，山北阴面有很多玉石。

    山中有一种野兽，形状像羊却没有嘴，不能轻易杀死它，名字叫䍺 huàn。

    洵水从这座山发源，然后向南流入阏泽，水中有很多紫色的螺。

再往东四百里，叫做虖 hū 勺山，

    山上有很多梓树和楠木，山下有很多荆树和杞树。滂水从这座山发源，然后向东流入大海。

又往东五百里，叫做区吴山，

    没有花草树木，有很多砂石。

    鹿水从这座山发源，然后向南流入滂水。

再往东五百里，叫做鹿吴山，

    山上没有花草树木，有很多金属和奇石

    泽更水从这座山发源，然后向南流入滂水。

    水中有一种野兽，名字叫蛊雕，形状像雕却有角，发出的声音如同婴儿的声音，是能吃人的。

往东五百里，叫做漆吴山，

    没有花草树木，有很多博石，没有玉石。它靠近大海，东边可以看到山丘，那片光影忽明忽暗，是太阳休息的地方

南方第二列山系，从柜山到漆吴之山，一共十七座山，七千二百里。这些山的山神的形貌都是龙的身子鸟的头。祭祀：祭祀用的羽毛和玉璧，埋入地下，祭祀的米用稻米。
